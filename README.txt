СПРАВОЧНИК СОТРУДНИКОВ — версия с админ-панелью и кабинетами

ЗАПУСК
1. Установите Python 3.10 или новее.
2. В терминале перейдите в папку проекта.
3. Создайте виртуальное окружение (рекомендуется):
   python -m venv venv

   Windows: venv\Scripts\activate
   macOS/Linux: source venv/bin/activate

4. Установите библиотеки:
   pip install -r requirements.txt

5. Запустите:
   python app.py

6. Откройте http://127.0.0.1:5000

ПЕРВЫЙ ВХОД АДМИНИСТРАТОРА
Логин: admin
Пароль: admin123

ВАЖНО: сразу после первого входа измените пароль администратора.
В этой демонстрационной версии первоначальные учётные данные заданы в коде.
Для реального размещения задайте надёжный SECRET_KEY через переменную окружения,
отключите debug, добавьте смену пароля администратора, HTTPS и резервное копирование.

РОЛИ
Администратор:
- добавляет сотрудников и создаёт им логины/пароли;
- изменяет данные сотрудников;
- удаляет сотрудников и их учётные записи;
- управляет фотографиями.

Сотрудник:
- входит по логину и паролю, выданным администратором;
- просматривает справочник, ищет коллег и звонит по телефону;
- не может добавлять, изменять или удалять сотрудников.

СОВМЕСТИМОСТЬ
Приложение пытается автоматически добавить недостающие поля в employees.db
из предыдущей версии проекта. Сделайте резервную копию базы перед обновлением.
Если у старых записей нет логинов и паролей, администратор может создать новые
учётные записи, добавив сотрудников заново или обновив базу вручную.

ХРАНЕНИЕ
employees.db — база SQLite.
static/uploads — загруженные фотографии.
